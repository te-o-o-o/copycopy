copycopy

A clipboard manager that remembers everything you copy, except your passwords.

Download for macOS Source on GitHub

Version 0.6.0, free and open source, for Windows, macOS and Linux; the zip and .deb are on the releases page.

The builds are not signed yet: how to open them

On Windows, choose More info, then Run anyway. On macOS and Linux, run this once:

# macOS
xattr -dr com.apple.quarantine /Applications/copycopy.app
# Linux
chmod +x copycopy-linux-x86_64.AppImage

    What it does
    
    
    One shortcut opens it over whatever you are doing. Type a few letters, press Enter, and the entry is back in your clipboard.
    
    
      
      
    • 
        Captures everything
      Text, code, links, images and files, with the app each one came from.
      • 
      
    • 
        Finds any fragment
      Search the whole history, not just what fits on screen, and filter by type.
      • 
      
    • 
        Code in colour
      The language is recognised from the snippet and from the app you copied it in.
      • 
      
    • 
        Files go back as files
      Paste them into a folder, a chat or a mail, or drag them out of the list.
      • 
      
    • 
        Secrets are never stored
      Whatever a password manager marks as confidential is dropped before it is written.
      • 
      
    • 
        Nothing leaves your machine
      No account, no cloud, no telemetry. Portable mode keeps it all in one folder.
      • 
      
    • 
        Pin and auto-paste
      Keep what you reuse at hand. The entry can land right where your cursor was.
      • 
      
    • 
        Fast
      A hundred thousand entries, still 59 frames per second.
      • 
    
    
  
    

  
    
    
    The keys
    
    
    The keyboard does it all; the mouse works too.
    
    
    
      
    Open the window
    ⌘⇧V on macOS, CtrlAltV elsewhere
    
      
    Search
    just type
    
      
    Copy back and close
    Enter
    
      
    Pin
    CtrlB
    
      
    Filter by type
    Ctrl1…6
    
      
    Close
    Esc
    
    
    
  
    

  
    
    
    Three pairs of themes
    
    
    Each pair has a light and a dark side, following your system. This page shows the side your system is on.
